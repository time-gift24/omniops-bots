# Spec Delta

## Purpose

客户端主对话界面的消息输入区：承载用户的文本输入、附件与发送控制，是用户发起每个对话回合的入口。

## ADDED Requirements

### Requirement: 文本输入与发送

输入区 SHALL 提供多行文本输入，Enter 发送、Shift+Enter 换行。输入为空或仅空白字符时发送入口 SHALL 不可用。发送成功后输入区 SHALL 清空并恢复可输入状态。

#### Scenario: 键盘发送

- **WHEN** 用户在输入区键入文本并按下 Enter
- **THEN** 消息被发送，输入区清空；按下 Shift+Enter 则插入换行而不发送

#### Scenario: 空输入

- **WHEN** 输入区为空或仅含空白字符
- **THEN** 发送按钮处于禁用状态

### Requirement: 发送中与停止

agent 响应进行期间，输入区 SHALL 保持可用以便用户继续键入下一回合，发送入口 SHALL 切换为停止入口；触发停止 SHALL 终止当前回复的继续输出，已输出的内容保留在线程中。

#### Scenario: 停止流式回复

- **WHEN** agent 回复正在输出，用户触发停止
- **THEN** 回复停止增长，已输出部分保留，发送入口恢复为发送

### Requirement: 附件

输入区 SHALL 支持添加本地文件作为附件，附件以可移除的条目呈现于输入区域上方；移除附件不影响已输入文本。

#### Scenario: 添加与移除附件

- **WHEN** 用户选择若干文件
- **THEN** 每个文件以条目呈现并可单独移除；发送时附件随消息一并提交

### Requirement: 视觉与交互一致性

输入区 SHALL 使用项目设计令牌：白底实色、1px 边框、聚焦时签名色描边与光环；其内部浮层（菜单、tooltip）允许磨砂质感。输入区宽度与阅读列一致并停靠于线程底部。

#### Scenario: 聚焦反馈

- **WHEN** 输入区获得焦点
- **THEN** 边框转为签名色并出现聚焦光环，反馈时长在 150–250ms 区间
