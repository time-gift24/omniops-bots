# 平台能力目录的填写约定

这是模板包的目录填写说明，不是已登记的平台清单。维护者依据真实平台信息填写后才能用于路由；未填写或仍有未确认事实的条目不得作为执行依据。

每个平台建立一条记录，使用以下字段：

| 字段 | 填写内容 |
| --- | --- |
| 平台与 Skill | 平台正式名称、操作 Skill 名称，例如 `ops-cdas`；示例名称不代表已提供 CDAS 的真实能力 |
| 定位与职责 | 平台负责的运维对象和业务环节、适用范围、不负责的事项 |
| 场景与能力 | 何种任务应选择本平台；能读取或变更哪些对象 |
| 使用条件 | 支持环境、所需上下文和必要接入条件；详细权限以平台 Skill 为准 |
| 周边关系 | 上下游平台、关系方向、何时需要联合使用 |
| 输入与交接 | 输入对象的标识、来源、环境；输出给哪个平台、哪些字段、如何核实 |
| 维护依据 | 平台说明或经验证实践的来源与最近核对日期 |

把具体操作步骤和页面定位留在对应平台 Skill 的实践中。平台目录只保留支持选择和组合的必要信息，避免维护两套相互矛盾的操作说明。
