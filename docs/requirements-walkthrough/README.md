# OmniOps Bots · MVP 需求串讲

[打开逐章串讲入口](./index.html) · [查看完整规格 Issue #3](https://github.com/time-gift24/omniops-bots/issues/3)

本目录包含 8 章目标设计与 1 章前端现状盘点。串讲页面沿用现有 Web 的暖灰底色、绿色强调、Geist / MiSans 字体与导航风格；对应章节加入原始 Web 截图，点击可放大。截图中的资源与执行数据为演示内容。

这组文档用于讲清已确认的目标设计，**不表示相关功能已经实现**。每章都按「US → 简要设计 → 服务端 → 客户端 → 详细设计」展开，先讲谁要做什么，再讲职责与关键流程。

| 章节 | 一句话讲清 | 主图 |
| --- | --- | --- |
| [00 总体架构](./00-总体架构.md) | 服务端编排与管理物料，客户端实际干活 | [架构图](./diagrams/00-overview.html) |
| [01 SKILL](./01-SKILL.md) | 完整包固定快照，正式发布联动 Agent | [发布 / 实验流程](./diagrams/01-skill.html) |

建议串讲顺序：先用 00 定分工；01–04 讲清物料与版本；06–07 串起一次调用；最后用 05 区分桌面更新与物料同步，再看 08 汇总前端缺口。逐章入口按文件编号排列，也支持直接跳章。

读图约定：US 中的小人、椭圆和无方向线表示角色与用例的关系，不表示执行顺序；详细设计使用架构图、流程图、时序图和生命周期图表达不同问题。主图为矢量 SVG，交互图可缩放、切换主题和导出。颜色只辅助区分，节点与关系都有文字标签。

特别保留的边界：`v.1.0.0` 是 Skill / Agent 的人工发布标签；桌面应用采用其更新规格的 SemVer。MCP 服务不纳入本项目发布版本，builtinTool 随桌面端交付，模型参数只进入运行快照。正式发布、运行快照与执行记录是不同对象。

依据为当前会话确认内容、Issue #3，以及 2026-10-18 已确认的客户端整包更新规格；旧更新规格中的审批场景不引入本次 MVP。协议字段、具体磁盘布局和超时默认值不在本组文档继续展开。

图形来源与质量证据位于 `diagrams/` 和 `evidence/`；正文与 SVG 可直接随目录一并分享。完整校验清单见 [交付验收记录](./evidence/验收记录.md)。
