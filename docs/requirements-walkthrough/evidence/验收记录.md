## 业务复核

客户端管理资源、装配与执行；服务端仅提供身份权限、官方物料、调用取消、结果确认和更新产物。权限、完整包版本、手填不可变标签、固定会话快照、忙时拒绝、断线补传、重启不续跑，以及取消／超时不回滚的规则保持不变。

本次明确了提示词随 Agent 发布、Skill 固定完整包、builtinTool 实现随桌面、MCP 配置随 Agent 而外部服务不纳版本的边界；运行模型覆盖装配成功、MCP 失败与周发布。语义复核确保文件下载由客户端校验并落盘，失败记录不写入 Skill 缓存，新会话使用所选新版，旧会话保持原快照。此前人工登录图的远端任务入口修订记录保留。

自动回执中的 `visualReview: pending` 保持原样；它不代替图像复核，独立视觉记录绑定具体 HTML 哈希。旧 `reader-browser.json`、旧主图验证和早期阅读页复核均为历史证据，当前阅读页以 `reader-redesign-browser.json` 为准。

SVG 通过图形查看器原生导出；行尾空白与末尾换行的规范化单独记录。此前已安装指定 File Manager 组件，浏览器使用 IndexedDB，桌面 JavaScript runtime 写入 `.omnimind-ops/skills`。官方缓存按内容 ID 分目录、管理接口只读；当前运行仍每轮拼接 `SKILL.md`，完整包挂载和会话固定快照明确列为后续接入。具体目录、版本与 LangGraph.js 配置见 [Skill 存储与运行加载](../../skill-storage-and-loading.md)。
